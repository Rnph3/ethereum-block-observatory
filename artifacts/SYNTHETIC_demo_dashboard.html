Method and limitations

Execution gas utilization = gasUsed/gasLimit; base-fee burn = gasUsed × baseFeePerGas. The latter excludes blob base fees, priority tips, MEV and other economics. Only the previous 12 blocks enter each robust anomaly baseline.

This small header sample does not measure total Ethereum users, DeFi TVL, token transfers, stablecoins, or financial profit. RPC snapshots may differ across providers at forks. See the GitHub README and sources.
