**Ethereum Block Observatory (Python, Ethereum JSON-RPC, Data Engineering)**

Built a read-only Ethereum execution-layer block header analysis pipeline that validates chain identity, block continuity and source metadata. Calculates EIP-1559 base-fee metrics and gas utilization, flags high-utilization blocks with past-only statistics, and renders a standalone SVG/HTML report. Includes deterministic synthetic demo data and an opt-in live RPC collector. The network collection mode was not exercised during the offline build; current demo results are explicitly labeled synthetic.
